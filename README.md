# xNovel -小説家になろうダウンローダー-

**xNovel** は、「小説家になろう」の作品（Nコード）から概要および全話の本文を取得し、一覧表示・閲覧・テキストファイルとして一括保存ができるElectronベースのデスクトップアプリケーションです。

---

## 💡 主な機能

- **Nコード検索 & 即時取得**
  - Nコードを入力して検索ボタン（またはEnterキー）を押すだけで、作品概要および全エピソードの本文を自動取得。
  - 取得中は進捗プログレスバーで現在の進捗状況を表示。
  - 検索中の「中止（キャンセルの実行）」にも対応。
- **サイドバーのレスポンシブ・リサイズ**
  - エピソード一覧が表示されるサイドバーの右端をドラッグ＆ドロップすることで、お好みの幅に自由に変更可能。
  - サイドバーの幅変更に合わせて、右側のテキストビューア領域も自動伸縮。
- **テキストファイルの一括保存**
  - 取得した概要・全エピソードをテキストファイル（.txt）として指定フォルダへ一括保存。
  - 保存先フォルダ内に自動で **`Nコード：タイトル`** 形式のサブフォルダを作成して保存（既存フォルダがある場合は上書き・追加保存）。
- **ダークモード / ライトモード対応**
  - ヘッダーのトグルボタン（☀️ / 🌙）で簡単にテーマの切り替えが可能。
- **ユーザーフレンドリーな通知機能（トースト表示）**
  - エラーや保存完了などの通知を画面上部にトーストメッセージで表示（ホバー時のタイマー一時停止・クリックでの即時閉じに対応）。

---

## 画面構成・インターフェース

1. **ヘッダーエリア**
   - Nコード入力欄（起動時自動フォーカス / Enterキーで検索）
   - 検索 / 中止ボタン（🔎）
   - 保存ボタン（📁）
   - ダーク/ライトモード切り替えボタン
2. **サイドバー（左側）**
   - 作品タイトル表示
   - 概要および全エピソードのタイトル一覧（クリックでビューア表示）
   - 右端のドラッグによる幅調整機能
3. **メインビューア（右側）**
   - 選択したエピソード（または概要）の本文表示エリア
4. **ステータスバー & 進捗バー（下部）**
   - 現在の処理状況およびプログレスバーを表示

## 🛠️ 技術スタック

- **フレームワーク**: [Electron](https://www.electronjs.org/)
- **フロントエンド**: HTML5, CSS3, JavaScript (ES6+)
- **通信**: Electron IPC (`ipcMain` / `ipcRenderer` / `preload.js`)
- **ファイル操作**: Node.js `fs` / `path`
