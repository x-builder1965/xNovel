# xNovel - 小説家になろうダウンローダー - （xNovel-Windows）

xNovel は、「小説家になろう」および「ノクターンノベルズ」の作品を検索し、作品概要と本文を取得・閲覧して、テキストファイルとして保存する Windows 向けデスクトップアプリです。

## 主な機能

- Nコードを指定して作品情報と本文を取得します。Nコードは大文字・小文字を区別しません。
- 「ノクターン(18禁)モード」を切り替えて、通常作品またはノクターンノベルズの作品を検索できます。
- 作品概要、連載中・完結済の状態、話数を表示し、取得した概要・各話本文をアプリ内で閲覧できます。短編作品にも対応しています。
- 取得中・保存中の進捗を表示し、取得処理を中止できます。
- 保存する項目を個別に選択できます。「全選択」「全解除」ボタンで一括切り替えもできます。
- ダークモード／ライトモードを切り替えられます。
- エピソード一覧のサイドバーは、右端をドラッグして幅を調整できます。
- アプリ名をクリックするとヘルプ、バージョン表示をクリックすると変更履歴を表示します。

## 使い方

1. アプリを起動し、Nコードを入力します。
2. ノクターンノベルズの作品を取得する場合は、検索前に 🔞 ボタンを有効にします。
3. 🔎 ボタンをクリックするか、Nコード入力中に Enter キーを押して検索します。
4. 左側のリストから概要またはエピソードを選ぶと、右側に本文が表示されます。チェックボックスで保存対象を選択します。
5. 💾 ボタンをクリックして保存先フォルダを選択します。選択した項目は UTF-8 のテキストファイルとして作品フォルダに保存され、そのフォルダ名に `.zip` を付けた ZIP ファイルに圧縮されます。ZIP の作成後、作品フォルダはゴミ箱に移動します。

保存先には `Nコード：掲載状況_作品タイトル.zip` という名前の ZIP ファイルを作成します。ZIP 内には同名の作品フォルダが含まれます。概要は `0000_概要.txt`、各話は連番とサブタイトルを含むファイル名で保存されます。同名のテキストファイルおよび ZIP ファイルがすでにある場合は上書きされます。

## キーボード操作

| 操作 | ショートカット |
| --- | --- |
| テーマ切り替え | `Ctrl+T` |
| 検索／検索中止 | `Ctrl+N` |
| 選択項目を保存 | `Ctrl+S` |
| 保存対象を全選択 | `Ctrl+E` |
| 保存対象を全解除 | `Ctrl+R` |

Nコード入力欄では `Enter` キーでも検索できます。

## 動作環境

- Windows
- Node.js と npm（ソースから起動・ビルドする場合）

## 開発環境のセットアップ

```bash
git clone https://github.com/x-builder1965/xNovel.git
cd xNovel
npm install
npm start
```

## Windows 向けビルド

| コマンド | 内容 |
| --- | --- |
| `npm run build` | Windows 向けインストーラーをビルド |
| `npm run dist` | Windows x64 向け配布物をビルド |
| `npm run dist:32` | Windows ia32 向け配布物をビルド |
| `npm run dist:portable` | Windows x64 向けポータブル版をビルド |

ビルド成果物は `dist-win` フォルダに出力されます。

## 技術スタック

- Electron 30
- HTML、CSS、JavaScript
- Node.js（ファイル操作、ネットワーク通信）
- Cheerio（作品本文のHTML解析）
- Electron IPC（メインプロセスとレンダラープロセス間の通信）

作品情報は「小説家になろう」のAPIから取得し、本文は各作品ページから取得します。ご利用の際は各サービスの利用規約をご確認ください。
